## Self-Service Cancellation

Customers can cancel an order themselves, free of charge, while it is
still being prepared for shipment — that is, while the order status is
**Placed** or **Confirmed**.

### How to Cancel

The customer (or the copilot, via the order-lookup tool) checks the
order's current status, then cancels it if it is still Placed or
Confirmed. Once cancelled, any payment already collected is refunded per
`refund-payout-timelines.md`.

### Once an Order Has Shipped

Self-service cancellation stops being available once the order's status
changes to **Shipped** — see `post-shipment-cancellation-exception.md`
for exactly how that request should be handled.
