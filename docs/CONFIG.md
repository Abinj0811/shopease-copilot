# Configuration registry

Every configurable value (ports, URLs, keys, model aliases, thresholds, counts, paths) must have one row here, and this file must be updated in every step that adds or changes one.

| Name | Purpose | Default | Where set | Example alternative |

| POSTGRES_PASSWORD | Postgres password (required, no default; Compose fails if unset). Must also be kept in step with the password inside LITELLM_DATABASE_URL. Note Postgres only applies this at first init: to change it on an existing volume, run `ALTER USER <POSTGRES_USER> WITH PASSWORD '<new>'` and update both .env entries | none, `.env` only | .env | a long random URL-safe string |
