# Configuration registry

Every configurable value (ports, URLs, keys, model aliases, thresholds, counts, paths) must have one row here, and this file must be updated in every step that adds or changes one.

| Name | Purpose | Default | Where set | Example alternative |
|---|---|---|---|---|
| POSTGRES_USER | Postgres superuser name | shopease | .env | copilot_admin |
| POSTGRES_PASSWORD | Postgres password (required, no default; Compose fails if unset) | none, `.env` only | .env | a long random string |
| POSTGRES_DB | Database created on first start | shopease | .env | shopease_dev |
| POSTGRES_PORT | Host port mapped to Postgres (bound to 127.0.0.1) | 5432 | .env | 5433 |
| REDIS_PORT | Host port mapped to Redis (bound to 127.0.0.1) | 6379 | .env | 6380 |
| POSTGRES_HOST | Host the app and scripts use to reach Postgres | 127.0.0.1 | .env | postgres (from inside Compose) |
| REDIS_HOST | Host the app and scripts use to reach Redis | 127.0.0.1 | .env | redis (from inside Compose) |
| INFRA_CHECK_TIMEOUT_SECONDS | Connect timeout in seconds for scripts/check_infra.py | 5 | .env | 15 |
| OLLAMA_BASE_URL | Ollama's OpenAI-compatible base URL (includes `/v1`) | http://127.0.0.1:11434/v1 | .env | http://host.docker.internal:11434/v1 (from inside Docker) |
| OLLAMA_CHECK_TIMEOUT_SECONDS | Request timeout in seconds for scripts/check_ollama.py (cold model load can be slow on CPU) | 120 | .env | 300 |
| OLLAMA_CHECK_MAX_TOKENS | Max tokens generated by scripts/check_ollama.py | 256 | .env | 64 |
| OLLAMA_CHECK_PROMPT | Default short prompt for scripts/check_ollama.py (`--prompt` overrides it) | Reply with one short sentence: what is ShopEase? | .env | Say hello in five words. |
| OLLAMA_API_BASE | Ollama server URL for LiteLLM's native ollama/ollama_chat providers (no `/v1`); must resolve from inside the litellm container | http://host.docker.internal:11434 | .env | http://127.0.0.1:11434 (running LiteLLM directly on the host, outside Docker) |
| GROQ_API_KEY | Groq API key for the `strong` chat alias in gateway/config.yaml (free tier) | none, `.env` only | .env | your key from console.groq.com |
| LITELLM_PORT | Host port mapped to the LiteLLM Proxy container | 4000 | .env | 4001 |
| GATEWAY_BASE_URL | OpenAI-compatible base URL of the LiteLLM gateway, called from the host | http://127.0.0.1:4000/v1 | .env | http://127.0.0.1:4001/v1 (if LITELLM_PORT changes) |
| GATEWAY_API_KEY | API key sent to the gateway (OpenAI SDK requires a non-empty value) | sk-not-required-yet | .env | a real `sk-...` key, once LITELLM_MASTER_KEY is enabled |
| EVALS_GATEWAY_KEY | The `evals` team's own virtual key from scripts/create_keys.py; no consumer yet (the evals runner is a later step) | sk-not-required-yet | .env | a real `sk-...` key, once the evals runner reads it |
| LOADTEST_GATEWAY_KEY | The `loadtest` team's own virtual key from scripts/create_keys.py; no consumer yet (Locust load tests are a later step) | sk-not-required-yet | .env | a real `sk-...` key, once the load test config reads it |
| LITELLM_DATABASE_URL | Postgres connection string for LiteLLM's own DB (keys, spend logs); same server as the app DB, separate database name; must resolve from inside the litellm container, so host is the Compose service name `postgres`, not 127.0.0.1 | postgresql://shopease:change-me@postgres:5432/litellm | .env | a dedicated `litellm` role/password instead of reusing POSTGRES_USER |
| teams.copilot (models/max_budget/rpm_limit/tpm_limit) | Live-app team's allowed aliases, USD budget ceiling and rate limits, used when scripts/create_keys.py creates its virtual key | models: cheap, strong, embed; max_budget: 5.0; rpm_limit: 30; tpm_limit: 50000 | gateway/teams.yaml | raise tpm_limit for a higher-throughput demo |
| teams.evals (models/max_budget/rpm_limit/tpm_limit) | Golden-set/judge-run team's allowed aliases, budget and rate limits | models: cheap, strong, embed; max_budget: 2.0; rpm_limit: 20; tpm_limit: 50000 | gateway/teams.yaml | lower max_budget to force the CI eval-gate budget check to fail, for testing |
| teams.loadtest (models/max_budget/rpm_limit/tpm_limit) | Load-test team's allowed aliases, budget and rate limits; deliberately narrow since Locust should target a mock upstream, not real models | models: cheap; max_budget: 0.5; rpm_limit: 10; tpm_limit: 10000 | gateway/teams.yaml | drop max_budget to 0 to hard-block any real-model call from load tests |
| LITELLM_MASTER_KEY | Admin/master key for the LiteLLM proxy; enables its auth and is used by scripts/create_keys.py to call the admin API | sk-local-master-change-me | .env | a securely random `sk-...` value if this ever leaves localhost |
| LITELLM_DB_NAME | Database name of LiteLLM's own DB on the shared Postgres server, read directly by scripts/show_spend.py from the host (LITELLM_DATABASE_URL's host only resolves inside Docker); keep in step with the db name in LITELLM_DATABASE_URL | litellm | .env | litellm_prod |
| SPEND_LOG_DEFAULT_LIMIT | Default number of spend log rows scripts/show_spend.py prints (`--limit` overrides it) | 20 | .env | 50 |
